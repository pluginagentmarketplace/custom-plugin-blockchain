# /explore-roadmap

Explore developer roadmaps by role category.

## Usage

```
/explore-roadmap [category] [optional-filter]
```

## Description

This command helps you discover and explore the 65+ developer roadmaps available in the repository. You can browse by categories like Frontend, Backend, DevOps, Data Science, and many more.
