# /roadmap-compare

Compare different developer roles and learning paths.

## Usage

```
/roadmap-compare [role1] [role2] [optional-role3]
```

## Description

This command allows you to compare different developer roles side-by-side. See the skills, tools, salary ranges, and career progression for each role to make informed career decisions.

## Comparison Categories

### Core Skills
Compare technical skills required for each role:
- Programming languages
- Frameworks and libraries
- Databases and data management
- Tools and platforms

### Tools & Technologies
Compare the technology stack:
- Development tools
- Version control systems
- Testing frameworks
- Deployment platforms

### Soft Skills
Compare professional requirements:
- Communication needs
- Leadership requirements
- Problem-solving approaches
- Collaboration styles

### Career Progression
Compare growth paths:
- Entry-level positions
- Mid-level roles
- Senior positions
- Leadership opportunities

### Learning Time
Compare typical learning curves:
- Time to basic competency
- Time to intermediate level
- Time to advanced level
- Time to expertise

### Job Market
Compare employment landscape:
- Job availability
- Salary ranges
- Geographic demand
- Remote opportunities

## Popular Comparisons

### Frontend vs Backend
```
/roadmap-compare frontend backend
```
Learn the differences and overlaps between frontend and backend development.

### Junior Engineer Paths
```
/roadmap-compare frontend backend fullstack
```
Compare three popular starting roles for new developers.

### Specialization Paths
```
/roadmap-compare devops data-science mobile
```
Explore different specialization options.

### Leadership Paths
```
/roadmap-compare engineering-manager tech-lead product-manager
```
Compare paths toward leadership roles.

## Comparison Output

Each comparison includes:

1. **Quick Overview Table**
   - Difficulty level
   - Learning time
   - Job availability
   - Salary range

2. **Skills Comparison**
   - Common skills
   - Unique skills per role
   - Skill overlap percentage

3. **Tools & Tech Stack**
   - Primary languages
   - Popular frameworks
   - DevOps tools
   - Testing frameworks

4. **Career Path**
   - Typical career progression
   - Specialization options
   - Cross-role opportunities

5. **Learning Resources**
   - Recommended courses
   - Best books
   - Practice platforms
   - Communities

6. **Salary & Market**
   - Typical salary ranges
   - Geographic variations
   - Growth projections
   - Job market health

## Decision Framework

Use comparisons to consider:

1. **Interest Alignment** - Does the role match your interests?
2. **Skill Match** - Do you have foundational skills?
3. **Learning Effort** - How much time will it take?
4. **Market Demand** - Are there jobs available?
5. **Salary Expectations** - Does compensation match?
6. **Growth Potential** - What's the career trajectory?
7. **Team Fit** - What team environment suits you?
