# /skill-assessment

Assess your skills and get personalized recommendations.

## Usage

```
/skill-assessment [role]
```

## Description

This command helps you evaluate your proficiency level across different competencies in your target role. It provides a comprehensive assessment framework and actionable recommendations for skill improvement.

## Roles Available

- Frontend Developer
- Backend Developer
- Full-Stack Developer
- DevOps Engineer
- Data Scientist
- Machine Learning Engineer
- Mobile Developer
- Security Engineer
- Product Manager
- Engineering Manager

## Assessment Framework

### Beginner (0-6 months)
- Knows basic concepts
- Can follow tutorials
- Limited real-world experience
- Needs significant guidance

### Intermediate (6-18 months)
- Solid understanding of fundamentals
- Can build simple projects independently
- Some real-world experience
- Occasional need for help on advanced topics

### Advanced (18-36 months)
- Expert-level knowledge
- Can design and build complex systems
- Extensive real-world experience
- Can mentor others on some topics

### Expert (3+ years)
- Mastery of the domain
- Can innovate and optimize
- Deep real-world experience
- Can lead teams and make architectural decisions

## Skills Categories

### Technical Skills
- Language/Framework proficiency
- Tool and library knowledge
- System design capabilities
- Performance optimization
- Security understanding

### Professional Skills
- Communication ability
- Problem-solving approach
- Code quality standards
- Testing practices
- Documentation quality

### Domain-Specific Skills
- Best practices knowledge
- Industry patterns recognition
- Emerging technologies awareness
- Certification relevance

## Assessment Results

You'll receive:

1. **Overall Level** - Your current proficiency
2. **Strength Areas** - Where you excel
3. **Growth Areas** - Where to focus improvement
4. **Recommended Learning** - Specific topics to study
5. **Next Steps** - Actionable recommendations
6. **Timeline** - Expected time to reach next level

## Examples

```
/skill-assessment frontend
/skill-assessment backend
/skill-assessment devops
/skill-assessment data-scientist
```

## How to Use Results

1. **Review Your Strengths** - Build on what you know well
2. **Focus on Gaps** - Dedicate time to learning areas
3. **Practice** - Apply new knowledge in projects
4. **Get Feedback** - Share work for code reviews
5. **Reassess** - Track progress regularly

## Benchmark Expectations

### Frontend Developer
- **Beginner**: HTML, CSS, basic JavaScript
- **Intermediate**: React/Vue, responsive design, basic APIs
- **Advanced**: Complex state management, performance optimization
- **Expert**: Full-stack capable, architectural decisions

### Backend Developer
- **Beginner**: Basic REST APIs, simple databases
- **Intermediate**: Database design, authentication, caching
- **Advanced**: Microservices, scalability patterns
- **Expert**: Complex distributed systems design

### DevOps Engineer
- **Beginner**: Docker basics, Linux fundamentals
- **Intermediate**: Kubernetes, CI/CD pipelines
- **Advanced**: Infrastructure as code, monitoring
- **Expert**: Complex cloud architectures
