# /learning-path

Create personalized learning paths based on your goals and experience level.

## Usage

```
/learning-path [goal] [experience-level] [time-commitment]
```

## Description

This command generates a customized learning roadmap based on your target role, current experience level, and available time. It provides structured guidance for progressing from fundamentals to mastery.

## Parameters

### Goal (Required)
- `frontend` - Frontend development
- `backend` - Backend development
- `devops` - DevOps engineer
- `data-science` - Data scientist
- `mobile` - Mobile developer
- `fullstack` - Full-stack developer
- `security` - Security engineer
- `product-manager` - Product management
- `other` - Custom goal

### Experience Level
- `beginner` - No professional experience (default)
- `intermediate` - 1-3 years experience
- `advanced` - 3-7 years experience
- `expert` - 7+ years experience

### Time Commitment
- `part-time` - 5-10 hours/week
- `full-time` - 40+ hours/week
- `flexible` - Variable schedule (default)

## Learning Path Structure

Each path includes:

1. **Foundation Phase** (Weeks 1-8)
   - Core concepts and fundamentals
   - Essential tools and languages
   - First real project

2. **Intermediate Phase** (Weeks 9-16)
   - Advanced concepts
   - Framework/library mastery
   - 2-3 substantial projects

3. **Advanced Phase** (Weeks 17-24)
   - Specialization focus
   - Performance optimization
   - Production-ready systems

4. **Mastery Phase** (Weeks 25+)
   - Expert-level techniques
   - Contributing to ecosystem
   - Teaching and mentoring

## Examples

```
/learning-path frontend beginner full-time
/learning-path backend intermediate flexible
/learning-path devops advanced part-time
/learning-path fullstack beginner full-time
```

## What You'll Get

- **Weekly breakdown** of topics to study
- **Recommended resources** for each topic
- **Hands-on projects** to build
- **Milestone checkpoints** to track progress
- **Skills checklist** for self-assessment
- **Time estimates** for each topic

## Related Commands

- `/explore-roadmap` - Browse available roadmaps
- `/skill-assessment` - Evaluate current skills
- `/roadmap-compare` - Compare learning paths

## Success Tips

1. **Consistency** - Study regularly, even for short periods
2. **Projects** - Build real projects alongside learning
3. **Feedback** - Get code reviews from experienced developers
4. **Community** - Join communities in your learning domain
5. **Mentorship** - Find a mentor in your target role
